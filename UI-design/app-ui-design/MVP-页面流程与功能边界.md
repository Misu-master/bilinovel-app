# 哔哩轻小说 App：首版 MVP 页面流程与功能边界

版本：v0.2 · 2026-09-25  
依据：`index.html`、现有亮/暗主题设计稿，以及用户确认的首版范围。  
本文件是**首版范围基线**；扩展想法见 [后续待办与待补充.md](后续待办与待补充.md)。当前仅整理设计与需求，不涉及 Flutter 编程。

## 1. 已确认的边界

- **平台：** 首发仅 Android。
- **重点页面：** 首页、分类列表页、书籍详情页。保留已有亮色/深色视觉方向。
- **底部导航：** 保留“首页 / 分类 / 书架 / 我的”四项；书架与我的仅为空白占位页，不设计业务内容，等待后续文档。
- **内容接口：** 用户后续提供接口文档。本文不臆测字段、请求方式、分页规则、排序参数或实际数据来源。
- **首版不提供：** 通知、下载、分享、亮度控制，以及账号、书架业务、阅读器和阅读进度等本轮未要求的功能。不设计章节/进度口径。

“首版重点页面”指三页的视觉、导航和页面状态。它**不等于**原讨论稿中的“阅读闭环”；本轮以“浏览书籍并查看详情”为结束点。

## 2. 首版主流程

```text
启动 → 首页 ──文库入口──> 分类列表 ──书籍条目──> 书籍详情
          │                     ^                      │
          └──推荐/榜单书籍───────┴──────────────────────┘

底部 Tab：首页 ↔ 分类 ↔ 书架（占位） ↔ 我的（占位）
书籍详情返回：回到进入详情前的页面，保留原列表位置与已选筛选。
```

首页推荐卡片、榜单的**书籍条目**可进入对应书籍详情；首页文库入口可切到分类页并预选该文库。底部 Tab 的“分类”是根页面，建议移除当前分类设计稿里的返回箭头，以免同一页面同时表现为根页和子页。首页“全部”可进入分类；“完整榜单”在没有独立榜单页时先隐藏，不留无效入口。上述入口映射属于设计建议，待接口文档到位后核对数据能否支持。

## 3. 三个重点页面的设计交付

| 页面 | 首版需要明确的内容 | 暂不承诺的内容 |
| --- | --- | --- |
| 首页 | Banner/推荐、热门文库、榜单书籍卡片、底部导航；点击书籍进入详情、点击文库进入分类；内容不足时的排版 | 通知中心、搜索结果页、独立完整榜单页、自动轮播策略 |
| 分类列表 | 文库/题材选择的视觉状态、排序栏、书籍卡片、长书名截断规则；点击书籍进入详情 | 具体筛选组合与排序参数、服务端分页/加载协议（待接口文档） |
| 书籍详情 | 封面及书籍资料、标签、简介展开/收起、目录预览的静态展示；返回来源页 | 开始/继续阅读、完整目录/选章、加入书架、下载、分享与更多菜单 |

**占位页约定：** 书架和我的保留底部 Tab 与页面标题，内容区留空，不加入登录、收藏、阅读进度或“功能待补充”等额外内容。它们是导航占位，不计入三页的业务交付。

## 4. 现有设计稿中尚未开放的入口

现稿用于表达未来产品全貌，不能把所有看起来可点击的控件默认为首版功能。制作首版交付稿时建议：

| 现稿入口 | 首版处理建议 |
| --- | --- |
| 首页搜索框、通知铃铛、“完整榜单” | 暂隐藏交互入口；若保留视觉，必须明确标注为非交互展示，并避免呈现为可用按钮。优先隐藏无法承接的铃铛和“完整榜单”。 |
| 详情“开始阅读”、底部“继续阅读”、加入书架、下载、分享、更多 | 本轮没有目标页面/能力，首版交付稿中建议隐藏相应操作区与固定 CTA，并重新检查详情页剩余内容布局。 |
| 详情“目录”及章节条目 | 可以作为信息预览展示，但不提供完整目录/点击选章；去掉暗示可跳转的箭头或交互样式。 |
| 分类的筛选、排序 | 设计选中/未选中样式与结果变化、空结果；实际可用选项和规则由接口文档确认，不预设接口能力。 |

隐藏首版未开放的控件是**交付稿修订建议**，不是对现有 HTML、PDF 和 PNG 的即时修改；这些原稿继续作为视觉参考保存。若希望保留某项入口并使其可用，应先明确目标页面和行为，再修改首版范围。

## 5. 三页共通的必要状态与规范

- 页面加载中、数据为空、请求失败并可重试；封面图片失败时有占位图。是否出现“空榜单/空分类”由实际数据决定。
- 分类筛选和排序要能看出当前选中项；从详情返回后保留列表的筛选条件与滚动位置。Android 系统返回键与顶部返回按钮应一致。
- 长书名、长简介、标签数量变化不能挤压封面或遮住底部导航；详情简介的展开/收起应有明确状态。
- 复核 Android 安全区和手势导航、不同手机宽度及较大系统字号；不把设计稿里的状态栏 26dp、手势区 16dp 当成所有设备的固定值。
- 复核亮/暗模式的正文与辅助文字对比度，以及 Android 至少 48dp 的可触达区域。现有 34–36px 图标按钮和浅色辅助文字需要在首版精修时处理。

## 6. 本轮完成标准

1. 三页的布局、进入/返回关系、可点击与不可点击区域清楚，没有通往未设计功能的假入口。
2. 首页和分类的书籍条目可对应到详情设计；分类页作为 Tab 根页的表现一致。
3. 三页至少有加载、空内容、请求失败的状态说明；书架和我的有统一的占位表现。
4. 设计稿与后续接口文档对照后，重新确认字段、筛选项、排序、列表加载方式，再进入具体开发。
