# 后续待办与待补充（不属于首版范围）

版本：v0.1 · 2026-09-25  
作用：收纳已有设计中的延伸思路，避免与 [首版 MVP 范围](MVP-页面流程与功能边界.md)混淆。以下均为**待补充/待决定**，不是已确认开发任务。

## A. 等待输入的资料

- [ ] 书籍相关接口文档：推荐/榜单、文库与题材、分类列表、书籍详情的字段、分页、筛选和排序能力，以及错误码和空数据示例。
- [ ] 封面、书名、简介等内容与品牌素材的来源和使用授权说明。现有网页存档与封面仅作设计参考，不能自动视为可上线素材。
- [ ] 书架与我的两页的产品说明：面向谁、展示什么、需要哪些账号或本地数据。
- [ ] 是否以及何时提供搜索、完整榜单、完整目录、阅读器等承接页面的需求文档。

## B. 后续页面与功能候选

| 候选 | 开始设计前需回答的问题 |
| --- | --- |
| 搜索与搜索结果 | 搜索范围、历史/建议词、无结果处理、接口能力。 |
| 完整榜单 | 榜单种类、排序口径、刷新周期、列表承接方式。 |
| 完整目录与阅读器 | 章节内容来源、卷/话/章关系、上一/下一章、阅读进度定义与恢复策略。 |
| 书架 | 收藏与阅读记录的关系、本地或账号同步、移出及空状态。 |
| 我的与账号 | 登录必要性、设置项、关于/反馈、跨设备同步范围。 |
| 通知 | 通知种类、权限时机、点击落地页、未读状态。 |
| 下载/离线 | 允许缓存的内容、容量与清理、失败恢复、授权限制。 |
| 分享与更多菜单 | 分享内容、可打开的落地链接、菜单项及权限。 |
| 亮度与阅读设置 | 系统亮度或应用内覆盖、日/夜主题、字号和排版的保存规则。 |

## C. 未来迭代的设计核对

- [ ] 为新页面补亮/暗主题及加载、空、错误、操作反馈状态。
- [ ] 为搜索、目录等入口确定导航返回与滚动位置恢复规则。
- [ ] 验证 Android 小屏、大字号、横屏及系统手势导航；若将来支持 iOS，再补平台差异稿。
- [ ] 统一设计令牌的对比度、图标触控范围、动态安全区和长文本换行。
- [ ] 统一示例数据：同一本书的标题、作者、目录、章节数与进度不能互相矛盾。

## D. 范围变更规则

若决定将以上任一候选加入首版，先更新 `MVP-页面流程与功能边界.md` 的页面清单、入口与状态，再修改精稿；不要仅在现有图标上接一个没有定义的动作。
